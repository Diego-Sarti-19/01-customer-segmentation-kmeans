Customer Segmentation with K-Means
  Overview
A machine learning project focused on customer segmentation using the K-Means clustering algorithm.
The project explores customer income and spending behavior to identify groups with similar characteristics and investigate potential business applications.
Objectives
  * Perform exploratory data analysis.
  * Apply feature scaling using StandardScaler.
  * Implement K-Means clustering.
  * Evaluate the number of clusters using the Elbow Method, Silhouette Score, and Calinski-Harabasz Index.
  * Visualize and profile the resulting customer segments.
  * Identify potential applications for data-driven marketing strategies.

Technologies
  * Python
  * Pandas
  * NumPy
  * Matplotlib
  * Seaborn
  * Scikit-learn
  * Jupyter Notebook
